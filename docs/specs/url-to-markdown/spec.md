# URL to Markdown

웹 페이지 URL을 붙여넣으면 본문을 Markdown으로 추출해 보여주고, 복사·다운로드하거나 프롬프트와 함께 ChatGPT·Claude로 넘기는 서비스입니다.

## Linked sources

- 결정 계약: [docs/decisions/dependency-versions.md](../../decisions/dependency-versions.md) — 새 의존성을 추가할 때 버전 정책을 따릅니다.
- 외부 문서: https://defuddle.md/docs — defuddle 사용법.
- 프로토타입: [prototype.html](prototype.html) — 승인된 화면 구성과 흐름(입력, 변환 중, 결과, 오류, 프롬프트 선택, 내보내기, 다크모드 토글)의 참조입니다. 더미 데이터와 임시 동작이며 production 코드가 아닙니다. 폰트는 오프라인이라 시스템 폰트로 대체했으니 실제 구현은 프로젝트 폰트를 씁니다.

## 사용자에게 보이는 결과

1. **입력** — 한 화면에 URL 입력창과 변환 버튼이 있습니다. 입력창에 값이 있을 때 지우기 버튼이 나타나고, 누르면 입력과 결과가 모두 초기 상태로 돌아갑니다.
2. **변환** — 변환 버튼을 누르면 해당 페이지의 본문이 Markdown으로 추출됩니다. 변환 중에는 진행 중임이 보이고 버튼이 중복 실행되지 않습니다.
3. **결과 확인** — 결과 상단에 페이지 제목과 저자(없으면 저자 줄 생략)가 보이고, 그 아래에 Markdown이 렌더링되어 보입니다.
4. **내보내기**
   - 복사하기: 프롬프트(선택했다면)와 본문 Markdown을 클립보드에 복사하고 복사됐음을 알립니다.
   - .md 다운로드: 본문 Markdown을 `.md` 파일로 내려받습니다. 파일명은 페이지 제목에서 만들고, 제목이 없으면 기본 이름을 씁니다. 프롬프트는 파일에 넣지 않습니다.
   - ChatGPT로 열기 / Claude로 열기: 프롬프트(선택했다면)와 본문 전체를 클립보드에 복사한 뒤 해당 서비스의 새 대화 화면(`https://chatgpt.com/`, `https://claude.ai/new`)을 새 탭으로 엽니다. 사용자가 붙여넣어 보냅니다. 복사됐다는 안내와 "붙여넣기만 하면 됩니다"는 취지의 문구를 함께 보여줍니다.
5. **프롬프트** — 결과 영역에서 고릅니다.
   - 프리셋: "요약해줘", "한국어로 번역해줘", "쉽게 설명해줘". 하나를 고르면 다시 눌러 해제할 수 있고, 아무것도 고르지 않으면 본문만 전달됩니다.
   - "직접 입력": 프리셋 옆 선택지입니다. 고르면 텍스트 입력창이 나타납니다. 입력값은 저장하지 않고 새로고침하면 사라집니다. 비어 있으면 프롬프트 없음과 같습니다.
   - 프롬프트는 복사하기와 ChatGPT·Claude로 열기에서 본문 앞에 빈 줄을 두고 붙습니다. 다운로드에는 붙지 않습니다.
6. **다크모드** — 화면 어디서든 보이는 토글로 라이트와 다크를 바꿉니다. 첫 방문에는 시스템 설정을 따르고, 사용자가 바꾼 값은 다음 방문에도 유지됩니다.

## 오류 상태

- URL 형식이 잘못됐거나 http(s)가 아니면 변환 전에 입력창 근처에 안내합니다.
- 페이지를 가져오지 못했을 때(네트워크 오류, 4xx·5xx, 시간 초과)와 본문을 추출하지 못했을 때(결과가 비어 있음)는 각각 이유를 알리는 오류 메시지를 보여주고, 입력은 유지해 다시 시도할 수 있게 합니다.
- 오류가 나면 이전 결과는 보이지 않습니다.

## 수용 기준

- 공개된 정적 페이지(예: https://en.wikipedia.org/wiki/Markdown, https://defuddle.md/docs)의 URL을 넣으면 제목·저자 헤더와 렌더링된 Markdown이 나타납니다.
- 한국어 페이지도 변환되어 한글이 깨지지 않습니다.
- 변환은 defuddle로 수행합니다.
- 지우기 버튼은 입력, 결과, 오류, 선택한 프롬프트 모두를 초기화합니다.
- 복사한 내용은 프롬프트 선택 여부에 따라 "프롬프트 + 빈 줄 + 본문" 또는 "본문"과 정확히 일치합니다.
- 다운로드한 `.md` 파일의 내용은 화면의 본문 Markdown과 일치하고 프롬프트를 포함하지 않습니다.
- ChatGPT·Claude 열기 버튼을 누르면 클립보드에 위와 같은 내용이 들어가고 각 서비스의 새 대화 탭이 열립니다. 본문 길이로 내용이 잘리지 않습니다.
- "직접 입력"을 고르면 입력창이 나타나고, 프리셋을 고르면 사라집니다. 새로고침 후 입력값이 남아 있지 않습니다.
- 다크모드 토글이 전체 화면에 적용되고 새로고침 후에도 유지됩니다.
- 모든 상태(대기, 변환 중, 성공, 각 오류)가 ui-composition 계약에 맞는 같은 component 문법으로 표현됩니다. 좁은 화면에서도 모든 동작에 접근할 수 있습니다.
- 런타임 검증(`next-dev-loop`)으로 입력 → 변환 → 결과 → 내보내기 흐름이 실제로 도는지 확인합니다.

## 확정한 결정과 근거

- **defuddle 필수.** 사용자 요구입니다. 직접 확인한 결과 `defuddle@0.19.6`의 `defuddle/node`는 DOM 구현(linkedom 또는 jsdom)을 요구하고, 둘 다 위 두 영어 페이지와 한국어 페이지에서 같은 결과를 냈습니다(제목, 저자, 본문). Node 26에서 `markdown: true`로 Markdown이 바로 나옵니다. 호스팅 API(`defuddle.md/<url>`)는 요청 블록 과금이 있어 쓰지 않고 라이브러리를 직접 사용합니다.
- **LLM 전달은 클립보드 + 새 대화 열기.** 본문이 수만 자라 URL 쿼리에 다 담을 수 없고, 잘리면 LLM이 일부만 보게 되기 때문입니다. 사용자가 붙여넣는 한 단계가 늘어나는 비용을 받아들입니다. 쿼리 자동 입력과 길이별 전환 방식은 기각했습니다(잘림 또는 동작 이원화).
- **내보내기 배치는 한 카드.** 프롬프트 칩 아래에 복사하기, .md 다운로드, ChatGPT로 열기, Claude로 열기를 한 번에 둡니다. 다운로드를 분리한 안(B)과 하단 고정 바 안(C)을 비교했고 사용자가 A를 선택했습니다. 이 선택은 이 화면에만 해당하는 결정이어서 결정 계약으로 올리지 않습니다.
- **페이지 가져오기는 서버에서 합니다.** 브라우저에서 임의 사이트를 직접 가져오면 CORS로 막히기 때문입니다.

## 가정 (바꾸고 싶으면 알려주세요)

- 프리셋 문구는 화면 라벨과 동일하게 "요약해줘", "한국어로 번역해줘", "쉽게 설명해줘"를 그대로 프롬프트로 씁니다.
- 프롬프트 기본값은 "없음"입니다.
- 저자 필드가 비어 있으면 저자 줄을 숨깁니다. 사이트 이름 등 다른 메타데이터는 필요하면 보조로 보여줄 수 있습니다.
- 렌더링은 일반적인 Markdown 렌더러로 하며, 코드 블록·표·링크·목록이 읽을 수 있게 보이면 충분합니다.
- 다크모드 선택은 브라우저 저장소에 보관합니다(서버 저장 없음).

## 범위 밖과 이유

- 로그인이 필요한 페이지, 자바스크립트로 본문을 그리는 페이지의 완전한 추출. defuddle이 받은 HTML만 다룹니다.
- 변환 이력, 계정, 프롬프트 저장. 직접 입력은 1회용입니다.
- 서버 가져오기에 대한 사설망 접근 차단 등 보안 하드닝, 대용량·속도 방어. 강의용 템플릿 범위를 넘고 이 spec이 요구하지 않았습니다.
- ChatGPT·Claude 쪽 입력창 자동 채우기.

## 남은 위험

- 일부 사이트는 서버의 요청을 차단하거나 본문이 비어 나올 수 있습니다. 이때는 오류 상태로 안내합니다.
- 클립보드 쓰기는 브라우저 권한·보안 컨텍스트에 따라 실패할 수 있습니다. 실패하면 복사되지 않았음을 알립니다.
- ChatGPT·Claude의 새 대화 주소는 서비스 쪽에서 바뀔 수 있습니다.
